# Password Generator 🔐

A modern, fast, and secure client-side password generator built with HTML5, CSS3, and JavaScript. Uses the browser's cryptographically strong `crypto.getRandomValues()` API to generate truly random passwords.

## ✨ Features

- **Cryptographically Secure**: Generates passwords using `window.crypto.getRandomValues()`.
- **Customizable Length**: Range slider from 6 to 32 characters.
- **Character Options**: Toggle uppercase, lowercase, numbers, and special symbols.
- **Password Strength Indicator**: Real-time visual feedback based on character complexity and length.
- **One-Click Copy**: Instant clipboard copy with visual confirmation.
- **Responsive & Modern UI**: Glassmorphism design with animated background blobs.

## 🚀 Getting Started

Simply open `index.html` in any modern web browser or host it via GitHub Pages:

1. Clone the repository:
   ```bash
   git clone https://github.com/jesinmilesh/Password-Generator.git
   ```
2. Open `index.html` in your browser.
